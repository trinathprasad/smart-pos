# Smart POS

A modern offline billing and inventory management system built using Flask, SQLite, SQLAlchemy, and Bootstrap.

## ✨ Features

- Product Management
- Customer Management
- Billing & Invoice Generation
- PDF Invoice Export
- Dashboard Analytics
- Inventory Tracking
- Daily Sales Reports
- Search & Filtering

## 🛠️ Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- Bootstrap 5
- ReportLab
